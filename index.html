Global Economic Prediction

Problem
Economic indicators are difficult to compare consistently across countries and years.
Solution
A Power BI report covers historical indicators. The Streamlit dashboard adds inflation estimates, recession-risk indicators, anomaly flags and country groupings.
Data analysed
2,053 country-year records across 74 countries, spanning 1999–2026 in the final modelling dataset. The recession classifier used 411 records for testing.
Methodology
Cleaned and merged country-year records covering GDP, inflation, unemployment, trade, exchange rates and other financial indicators. Handled missing values, explored trends and correlations, and created economic scores, lagged variables and three-year rolling features.
Machine learning models
Random Forest Regressor for inflation, class-weighted Random Forest Classifier for a rule-based recession indicator, Isolation Forest for unusual observations, and K-Means (four clusters) for country segmentation. PCA projects the clusters onto two dimensions. The separate three-year trend projection compounds recent average growth.
Evaluation & selection
The inflation model recorded MAE 0.144, RMSE 0.587 and R² 0.485 on the notebook’s test split. The recession classifier matched its rule-based labels in the test split, where the inputs included the same GDP growth and unemployment used to define those labels. The notebook reports results by task.

Problem
The 2024 Stack Overflow Developer Survey contains many individual responses, making it hard to compare technology choices across respondent groups.
Solution

Customer Loyalty & Churn Analytics

Problem
Which members account for the most revenue, and which groups should a loyalty team prioritise for retention or reactivation?
Solution
Built a three-page Power BI report covering loyalty KPIs, customer value segments, and churn and retention.
Data analysed
3,214 loyalty programme customers. Purchase and redemption activity is analysed at the customer level.
Methodology
Combine member, purchase and redemption records. Use DAX to summarise activity, revenue and redemption. Segment customers by recency, frequency and monetary value (RFM), and use customer lifetime value (CLV) tiers to compare revenue contribution.
Findings
Of 3,214 customers, 782 had churned (24.33%), and 758 were classified as high risk. The top 20% generated 79.14% of revenue. These findings support separate campaigns for high-risk members and high-value Champions.

BNPL Credit Risk Dashboard

Problem
Credit risk teams need a consistent way to assess risk across buy now, pay later applications.
Solution
A Streamlit dashboard lets users explore credit risk predictions from a machine learning model.
Data analysed
10,345 BNPL records in the source dataset. The model comparison used 2,069 test records, including 808 defaults and 1,261 non-defaults.
Methodology
Handled missing values, removed unused IDs, converted booleans, one-hot encoded categorical variables and derived features from transaction dates. Explored financial and repayment patterns before training classifiers to predict default.
Machine learning models
Compared Logistic Regression, Random Forest, Gradient Boosting, AdaBoost, XGBoost and a Neural Network using accuracy, precision, recall, F1 and ROC-AUC.
Evaluation & selection
XGBoost ranked first on ROC-AUC (0.7824), followed by Gradient Boosting (0.7800) and AdaBoost (0.7761). Logistic Regression led on F1 (0.5969) and recall (0.5891). The notebook selected XGBoost by ROC-AUC.

Air Quality Prediction

Problem
Historical air quality readings show past conditions. Users also need a way to explore predicted conditions.
Solution
A Streamlit app makes air quality predictions accessible through an interactive dashboard.
Data analysed
Unit: hourly air-quality observation from a city. The training script samples up to 50,000 complete rows before the 80/20 split.
Methodology
Parsed hourly timestamps, extracted hour, day, month and day of week, and removed rows with missing values. Sampled up to 50,000 rows and used an 80/20 random split. The inputs include pollutant readings, UV index, European AQI and calendar features.
Machine learning models
The training script fits a Random Forest Regressor with 30 trees and a maximum depth of 12 to estimate PM2.5. It exports a compressed model for the Streamlit app.
Evaluation & selection
The training script evaluates the selected Random Forest with MAE and R². It runs a single model configuration.

Student Feedback Intelligence

Problem
Course teams need to see recurring issues across Coursera reviews and trace each theme back to the comments that support it.
Solution
Built a Databricks prototype that extracts multiple themes, sentiment and supporting quotes per review, with Power BI pages for trends, evidence and model evaluation.
Data analysed
Unit: written Coursera review linked to its course. The public project records 1099 reviews from held-out courses for baseline evaluation. The README does not report the full number of reviews processed.
Methodology
Built a Databricks ETL pipeline using PySpark and Delta tables. In Bronze, ingest and deduplicate raw Coursera review and course CSVs. In Silver, normalise review text, parse dates and ratings, redact email addresses and URLs, separate invalid records, and join course metadata. In Gold, validate the LLM-generated theme labels and check that each quoted excerpt appears in the cleaned review, then publish reporting tables for Power BI.
Models
Use databricks-gpt-oss-120b for structured theme, sentiment and evidence extraction. Train a class-weighted one-vs-rest Logistic Regression baseline on TF-IDF unigram and bigram features. Split by course so the test set contains unseen courses.
Evaluation
On 99 test reviews, the baseline achieved macro-F1 of 0.3824 and micro-F1 of 0.6469 against LLM-generated labels. General feedback had the highest per-theme F1 (0.85). These scores measure agreement with the LLM labels.

NSW Urban Context Benchmark

Problem
Traffic and mobility data alone provide limited context for explaining why urban activity changes during severe weather, major events or service disruptions.
Solution
Built a benchmark dataset across 24 NSW regions to test whether LLMs can use contextual signals for urban prediction and reasoning.
